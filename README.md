# portal

Monorepo do Portal Web e da API base (C#/.NET e Angular), conforme o ADR-0001.

- Repositório: https://github.com/tthiagoalvesmelo-hub/portal
- Espelho local: `/workspace/projetos/portal`
- Conhecimento, contratos e decisões: https://github.com/tthiagoalvesmelo-hub/stack-conhecimento

Este repositório é **público**. Não grave segredo, credencial, dado pessoal ou dado real em commit, arquivo ou mensagem.

A estrutura das aplicações (`apps/portal-api`, `apps/portal-web`, `scripts`) será criada pelo FS/OPS segundo o ADR-0001 (D6). Alterações em área protegida seguem PR real no GitHub (AH-0004): ramo `feat/<ID>-slug` (ou equivalente), revisão do CR quando aplicável, merge pelo dono da área; quem produz não aprova.
